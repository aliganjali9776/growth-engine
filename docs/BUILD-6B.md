# BUILD 6B — read-only Executive Advisor

Implemented in the existing Growth Engine by 1 Minute Manager project. The implementation is ready for local use with an explicitly selected mock provider, or for real analysis after server-side OpenAI configuration. **A live OpenAI call has not been verified: this environment has no API key. Mock QA is not evidence of live model quality or injection resistance.**

## Browser acceptance matrix

The requested 32 checks are covered as follows: 1–6 tests/types/build/start/page/no-provider passed; 7 used **explicit mock**, not a real credential; 8–20 executive and module questions, source interaction, comparisons, follow-up, session reset and long Persian input passed; 21 malicious context was tested in controlled unit fixtures to avoid altering existing business records; 22 provider failures were simulated in adapter tests, not induced against a live provider; 23 audit visible in `/dev/agent`; 24 domain preservation verified in tests and existing values inspected in UI; 25 reload retained session/evidence; 26–29 responsive/keyboard passed; 30–31 no captured console warnings/errors or hydration issues; 32 observed implementation issues fixed and regressions rerun.

No domain records were edited to perform Advisor QA. Only disposable Advisor session data was created on `localhost`; prior Agent artifacts and business stores were preserved.

## Configuration

Copy `.env.example` to `.env.local` locally and configure `AGENT_MODEL_PROVIDER=openai`, `OPENAI_API_KEY` and optionally `AGENT_OPENAI_MODEL`. Keep the real key out of chat, version control and `NEXT_PUBLIC_*` variables. Restart the server after changing configuration. Real model use sends the displayed selected business context and bounded session history to OpenAI; `store:false` is an API storage option, not a blanket zero-retention claim.

For offline demo, explicitly configure `AGENT_MODEL_PROVIDER=mock`, or enable `AGENT_ALLOW_MOCK_DEMO=true` and use the visible demo button. The running QA server uses the latter flag with the normal provider still `none`; no configuration file contains a credential.

Provider format follows the official [OpenAI Structured Outputs guide](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses). See [Advisor architecture](ADVISOR-ARCHITECTURE.md) for boundaries and practical limitations.
