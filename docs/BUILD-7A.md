## Limits to carry forward

Database schema and executable services are a foundation, not a completed SaaS migration. Existing UI still persists locally; database-backed product pages, identity provider and full production authorization are not wired. No independent PostgreSQL service was available to test TCP, multiple concurrent sessions or Compose startup. The load fixture is a basic index/scope sanity check on the embedded engine, not a production throughput benchmark.

Polymorphic Agent artifact references, full legacy UUID mapping and a few parent-consistency rules need domain checks before exposing editors/import. Snapshot JSONB is deliberate history storage, not a replacement for future canonical relational writes. Approval FK validity does not establish approval decision, expiry or execution permission; no server Agent executor exists. Database administrators retain privileged access; production RLS, restricted database roles, operational audit retention and backups were outside this build.

Run `npm.cmd test`, `npm.cmd run test:database`, `npx.cmd tsc --noEmit` and `npm.cmd run build`. See [architecture and development setup](SAAS-DATA-ARCHITECTURE.md) and [complete inventory](DATA-INVENTORY.md).
